# Green Store LLC — Company Website

A responsive, multi-section company profile website built with plain HTML, CSS, and JavaScript. Ready for GitHub Pages.

## Included
- English-only responsive layout
- Mixed light and dark visual sections
- Home, About, Products, Values, and Contact sections
- Chess King product links
- Responsive mobile navigation
- Scroll reveal effects and reduced-motion support
- SEO metadata and SVG favicon

## Preview locally
Open `index.html` in a browser. For a local development server, use the VS Code Live Server extension.

## Publish with GitHub Pages
1. Create a GitHub repository named `green-store-llc.github.io` for a user/organization site, or any repository name such as `green-store-website` for a project site.
2. Upload the contents of this folder (not the ZIP file) to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The Pages section will show the live URL.

## Before publishing
- Confirm the public support email is `green.store.support@gmail.com`.
- Replace the CSS-built abstract brand mark with the official company logo if desired.
- Add the final privacy policy and terms pages when their approved text is ready.
- Confirm the Chess King Google Play listing is public; the current button points to the developer profile.
- Add a custom domain later if you own one.
