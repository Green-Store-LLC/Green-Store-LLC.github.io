# Green Store LLC — Company Website

A responsive company website for GitHub Pages, built with HTML, CSS, and JavaScript.

## Site contents

- Company home page with the official Green Store LLC logo
- Chess King product section and Google Play developer link
- Company contact links, social profiles, and values
- Chess King Privacy Policy, Terms of Service, and external account-deletion request pages
- Shared responsive styling and the Chess King app icon on legal pages

## Local preview

Open `index.html` in a browser or use the VS Code Live Server extension.

## GitHub Pages

The site is designed to publish from the `main` branch and repository root. Set this in **Settings → Pages → Build and deployment** if Pages is not already configured.
